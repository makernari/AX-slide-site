# AX 전문강사 과정 웹 강의교안

> 경영지원과 마케팅·SNS 실무를 위한 15일의 학습 여정을, 탐색부터 전체 화면 발표까지 하나의 웹 경험으로 연결합니다.

이 저장소는 **AX 전문강사 과정의 웹 강의교안 서비스**를 제공합니다.  
과정별 직접 접속, 모듈·일자 탐색, 슬라이드 발표가 브라우저 안에서 자연스럽게 이어지도록 설계된 GitHub Pages 기반 정적 사이트입니다.

## 서비스 바로가기

### [스마트 경영지원 강의교안 열기](https://makernari.github.io/AX-slide-site/backoffice/)

### [마케팅·SNS 콘텐츠 기획·브랜딩 강의교안 열기](https://makernari.github.io/AX-slide-site/marketing/)

### [수강생 실습 자료 다운로드](https://makernari.github.io/AX-slide-site/#/resources)

각 과정은 별도 주소로 바로 접속하며, 과정 선택 단계 없이 모듈과 학습 일자로 이동할 수 있습니다.

## 하나의 흐름으로 이어지는 발표 경험

```text
과정별 링크 접속
  → 모듈 선택
    → 학습 일자 선택
      → 슬라이드 탐색
        → 전체 화면 발표
```

학습자는 자신의 과정에 맞는 교안을 빠르게 찾을 수 있고, 강의자는 같은 화면에서 바로 발표를 시작할 수 있습니다.

### 과정별 콘텐츠 분리

- **스마트 경영지원** 과정과 **마케팅·SNS** 과정을 명확히 구분합니다.
- 두 과정이 함께 학습하는 내용은 공통 콘텐츠로 관리합니다.
- 과정별 사례와 표현이 다른 과정 화면에 섞이지 않도록 구성합니다.

### 발표에 집중한 탐색

- 모듈과 일자 단위로 원하는 수업 위치를 탐색할 수 있습니다.
- 이전·다음 이동과 키보드 탐색을 지원합니다.
- 전체 화면 상태에서도 연속해서 슬라이드를 발표할 수 있습니다.
- 마지막으로 확인한 교안 위치를 기억해 학습 흐름을 이어갑니다.

### 다양한 화면을 고려한 인터페이스

- 모바일, 노트북, 프로젝터 화면에 대응하는 반응형 레이아웃
- 키보드만으로도 이용할 수 있는 발표 탐색
- 본문 바로가기와 의미 있는 인터페이스 레이블
- 이미지 누락 시 상태를 알 수 있는 대체 화면

## 콘텐츠 원칙

이 서비스는 **강의교안과 수강생용 실습 자료를 서로 분리해 제공**합니다.

- 강사용 가이드, 발표자 노트, 내부 검수 기록은 포함하지 않습니다.
- 수강생용 예제·템플릿·샘플·실습 시작 파일은 별도 자료 화면에서 다운로드할 수 있습니다.
- 수강생용 HTML은 배포 링크에서 바로 열거나 개별 파일로 내려받을 수 있으며, 중복 ZIP 묶음은 배포하지 않습니다.
- 외부 자료 링크, QR 코드, 외부 페이지 iframe을 포함하지 않습니다.
- 실제 개인정보나 기관 내부자료를 사례로 사용하지 않습니다.
- 모듈별 상세 커리큘럼과 과정 구분을 그대로 유지합니다.

각 슬라이드는 하나의 핵심 메시지에 집중하며, 공통·경영지원·마케팅 콘텐츠의 역할을 명확하게 구분합니다.

### 런타임 구성

- `index.html` — 서비스 진입점
- `assets/css/app.css` — 화면과 반응형 스타일
- `assets/js/app.js` — 과정 선택, 탐색, 발표 동작
- `data/slide-manifest.json` — 슬라이드 순서와 과정 정보
- `assets/slides/` — 승인된 모듈별 슬라이드 이미지
- `downloads/guide-resources/` — 과정별·일자별 수강생 실습 자료

### 배포 안전장치

- `scripts/validate-manifest.js` — manifest와 이미지 자산의 정합성 검사
- `scripts/build-pages.mjs` — 허용된 파일만 Pages 산출물로 구성
- `.github/workflows/pages.yml` — 승인 후 실행하는 GitHub Pages 배포

## 로컬 실행

정적 파일 요청이 정상적으로 동작하도록 로컬 웹 서버를 사용합니다.

```powershell
python -m http.server 8000
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000/
```

## 검증과 빌드

배포 전 manifest와 이미지 상태를 검증합니다.

```powershell
node scripts/validate-manifest.js --require-images
```

검증을 통과한 파일만 `.pages-dist`에 구성합니다.

```powershell
node scripts/build-pages.mjs
```

정상 빌드 기준:

```text
슬라이드 이미지 535개
수강생 실습 자료 364개
Pages 산출물 909개
```

`.pages-dist`는 생성 결과물이므로 Git에서 추적하지 않습니다.

## 배포 원칙

GitHub Pages 배포는 자동 푸시 배포가 아니라 **명시적인 수동 실행**으로 진행합니다.

```text
콘텐츠 검수
  → manifest·이미지 검증
    → Pages 산출물 검사
      → 사용자 승인
        → GitHub Actions 수동 실행
```

배포 전 다음 조건을 모두 확인합니다.

- M05~M09 전체 슬라이드 존재
- 깨진 이미지와 잘못된 경로 없음
- 경영지원·마케팅 콘텐츠 혼선 없음
- 외부 링크와 비배포 자료 없음, 수강생용 자료만 포함
- 모바일·노트북·프로젝터 화면 정상
- 키보드 탐색과 전체 화면 발표 정상
