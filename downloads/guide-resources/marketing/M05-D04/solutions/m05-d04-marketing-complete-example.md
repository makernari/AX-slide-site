# M05-D04 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 캠페인 콘텐츠 개선 보고
- 입력: 캠페인 목표, 콘텐츠 반응, 채널별 관찰점이 담긴 전 차시 근거 노트
- 기대 결과: 전략 덱·인포그래픽·비교 보고서·경영진 요약·채널별 실행안
- 주요 위험: 관찰을 성과 원인으로 단정하거나 확인되지 않은 고객 반응을 추가하는 오류
- 최종 확인 역할: 캠페인 책임자와 브랜드 검토 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 전 차시의 교육용 소스 묶음과 출처 메모
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 콘텐츠 전략·캠페인 사례 슬라이드와 인포그래픽 제작
- 결과: 슬라이드 덱의 교육용 초안
- 검증: 원문 충실도
- 과정별 확인 역할: 캠페인 책임자와 브랜드 검토 역할
- 확인한 위험: 관찰을 성과 원인으로 단정하거나 확인되지 않은 고객 반응을 추가하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
