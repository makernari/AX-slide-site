# M08-D03 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 NOVA-TEA 브랜드 가이드 Q&A
- 입력: 제품 사실·브랜드 톤·금지 표현·채널 원칙이 담긴 교육용 가이드
- 기대 결과: 출처 있는 브랜드 답변, 모호 질문 재질문, 없는 혜택 거절, RAG 평가표
- 주요 위험: 문서에 없는 제품 효능·후기·할인을 만들거나 충돌 자료를 임의 선택하는 오류
- 최종 확인 역할: 브랜드 가이드 소유 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 제공된 교육용 규정 또는 브랜드 가이드와 검색된 문서 조각
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 브랜드·상품 질문에서 공식 자료 근거가 필요한 이유 확인
- 결과: 문서 기반 Q&A의 교육용 초안
- 검증: 출처 위치
- 과정별 확인 역할: 브랜드 가이드 소유 역할
- 확인한 위험: 문서에 없는 제품 효능·후기·할인을 만들거나 충돌 자료를 임의 선택하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 브랜드 가이드·상품자료 기반 Q&A 제작
- 결과: 정상·함정 질문 세트의 교육용 초안
- 검증: 답변 정확성
- 과정별 확인 역할: 브랜드 가이드 소유 역할
- 확인한 위험: 문서에 없는 제품 효능·후기·할인을 만들거나 충돌 자료를 임의 선택하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 톤·금지표현·사실·존재하지 않는 상품 정보 질문 테스트
- 결과: RAG 평가표의 교육용 초안
- 검증: 자료에 없는 질문의 거절
- 과정별 확인 역할: 브랜드 가이드 소유 역할

- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 마케팅 Q&A와 평가표 완성
- 결과: RAG 평가표의 교육용 초안
- 검증: 충돌 문서 처리
- 과정별 확인 역할: 브랜드 가이드 소유 역할
