# M08-D03 마케팅 실습자료

기준일: 2026-08-08

## 단독·연속 수강 원칙

- 이 과정만 수강해도 원자료·샘플·프롬프트·템플릿·완성 예시로 네 차시를 끝낼 수 있습니다.
- 오전·오후를 모두 수강해도 가상 조직·입력·기능·오류·최종 산출물을 반복하지 않습니다.
- 오전 경영지원과 달리 브랜드 톤·제품 팩트·채널 표현·자산 권리의 콘텐츠 답변을 검증합니다.

## 오늘의 과제

네 조각의 가상 브랜드·상품자료를 RAG 템플릿에 넣고 톤·금지표현·상품사실·권리 질문을 시험해 근거와 거절 여부를 평가합니다.

## 파일 구성

- starter/m08-d03-marketing-source-pack.md: 직무별 교육 원자료
- starter/m08-d03-marketing-starter.md: 차시별 시작 파일
- samples/m08-d03-marketing-samples.csv: 복사 가능한 가상 입력 데이터
- templates/m08-d03-marketing-practice-template.md: 빈 결과물 틀
- templates/m08-d03-marketing-prompt-pack.txt: 복사 프롬프트
- solutions/m08-d03-marketing-complete-example.md: 완성 예시

## 안전 기준

- 실제 개인정보·조직 내부자료·자격증명·API 키를 넣지 않습니다.
- 도구 기능·메뉴·요금·한도는 수업 계정에서 직접 확인합니다.
- 삭제·배포·발송·외부 등록은 사람 승인 없이 수행하지 않습니다.
- 브랜드 사실·채널·타깃·금지 표현·검토 상태를 사람이 최종 확인합니다.
