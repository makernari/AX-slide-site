# M08-D03 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

네 조각의 가상 브랜드·상품자료를 RAG 템플릿에 넣고 톤·금지표현·상품사실·권리 질문을 시험해 근거와 거절 여부를 평가합니다.

## 네 차시

1. 도서관 검색 비유로 일반 생성·파일 업로드·RAG 답변을 비교하고 네 브랜드 조각을 읽습니다.
2. 준비된 템플릿에 MK-R1~R4를 넣어 분할·검색·답변 흐름을 실행합니다.
3. MK-Q1~Q5로 정상·모호·문서 밖·충돌·권리 질문을 시험합니다.
4. 근거·팩트·거절·대체 카피를 평가하고 답변 규칙과 공유 권한을 정리합니다.

## 제출 결과물

- 가상 브랜드 색인표
- 정상·함정 질문 5종
- RAG 답변·대체 카피
- 팩트·권리 평가표

## 완료 기준

- [ ] 원자료의 요구사항·근거ID·허용·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 정상·빈 값·이상·지시문 입력을 분리해 시험함
- [ ] 브랜드 사실·채널·타깃·금지 표현·검토 상태를 원본과 대조함
- [ ] 도구 접근이 없을 때 카드·HTML·문서형 대체 결과를 완성함
