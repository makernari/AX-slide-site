# [M06-D01] 마케팅 이미지→캐릭터 시트→Flow·Veo 3.1 제작 실습

기준일: 2026-08-08

> 필수 제작 흐름 보강. ChatGPT Images 2.0 또는 Flow·Nano Banana Pro로 기준 이미지를 만들고, 캐릭터 시트·Ingredients/Frames를 거쳐 Flow의 현재 Veo 3.1 계열로 장면별 클립을 생성합니다.

## 최신 확인 카드

- ChatGPT 제품명: ChatGPT Images 2.0 / API 모델명: `gpt-image-2`. 이 수업은 ChatGPT 화면을 사용하므로 API 키가 필요하지 않습니다.
- Flow 이미지: Nano Banana Pro가 기본으로 보일 수 있으나 실제 선택 모델을 확인합니다. Flow 영상: 현재 Veo 3.1 계열의 지원 길이·비율·Ingredients/Frames 범위를 확인합니다.
- 화면에 기능이 없거나 크레딧이 부족하면 HTML 예시·캐릭터 시트·스토리보드·타임라인으로 같은 완료 상태를 만듭니다.

## 공통 안전선

- 실존 인물은 본인 또는 명시적 동의가 있을 때만 사용하며 기본 실습은 가상 인물입니다.
- 실제 회사·기관·고객 정보, 성과 수치, 로고, 자격증명, API 키를 넣지 않습니다.
- AI 결과의 얼굴·손·텍스트·제품 수·장면 연결을 사람이 확인합니다.
- 생성 결과를 실제 사건·제품 성능·착용감·업무 완료의 증거로 사용하지 않습니다.

## 실습 1. 제작 브리프·권리·출력 규격 잠그기

- 권장 시간: 10분
- 준비: NOVA-TEA 가상 출시 캠페인 영상 가상 브리프
- 완료 결과: 목적·대상·권리·비율·장면 수가 잠긴 브리프

1. 대상은 20~30대 가상 SNS 이용자, 목적은 가상 캠페인 교육용 예시로 한 줄씩 적습니다.
2. 실존 인물·실제 회사·고객 자료가 없는지 확인하고 9:16, 3개 장면, 장면당 짧은 클립으로 범위를 고정합니다.

## 실습 6. 3장면 스토리보드·샷 리스트

- 권장 시간: 20분
- 준비: 선택한 기준 이미지와 캐릭터 시트

1. 장면 1: 테이블 위 제품을 발견하고 시선을 둔다 / 장면 2: 제품을 들어 향을 경험하고 미소 짓는다 / 장면 3: 제품을 프레임 앞에 보여 주며 저장 행동을 유도한다. 세 장면을 한 행씩 적습니다.

3. 연결 컷에서 손 위치·시선·소품 위치가 갑자기 바뀌지 않는지 화살표로 표시합니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.


## 실습 7. Flow 캐릭터·Ingredients·Frames 준비

3. 각 장면에 시작 프레임 또는 Ingredients 중 실제 지원되는 방식을 선택하고 자산 대응표를 저장합니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.

## 실습 8. Flow·Veo 3.1로 장면별 클립 생성

## 실습 9. 일관성 검수·Scenebuilder·Vrew 인계

- 권장 시간: 15분
- 준비: 선택 클립 3개와 연속성 체크리스트
- 완료 결과: 선택 클립 3개·연속성 검수표·Vrew 인계 폴더

1. 얼굴·머리·의상·소품·공간·손·텍스트·왜곡을 장면별로 점검합니다.
2. Scenebuilder가 보이면 장면 순서와 앞뒤만 거칠게 정리하고, 최종 자막·음악·음량 편집은 하지 않습니다.
3. 클립을 다운로드해 파일명·장면 번호·버전·권리 상태를 확인한 뒤 Vrew 인계 폴더에 복사합니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.
