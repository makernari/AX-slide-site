# M06-D01 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 브랜드 NOVA-TEA 출시 포스터와 캠페인 영상
- 입력: 가상 허브티의 핵심 메시지, 성인 타깃, 제품 패키지 특징, SNS 캠페인 목적
- 기대 결과: 브랜드 포스터, 제품 일관성이 유지된 3장면, 캠페인 영상 프롬프트
- 주요 위험: 입력에 없는 효능·후기·할인·성과를 만들거나 패키지 특징이 장면마다 바뀌는 오류
- 최종 확인 역할: 브랜드 검토 역할과 콘텐츠 제작 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 직접 작성한 목적·대상·메시지와 교육용 가상 소재
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 문제가 있는 브랜드·상품·이벤트 포스터 분석
- 결과: 포스터 전후본의 교육용 초안
- 검증: 핵심 메시지의 가독성
- 과정별 확인 역할: 브랜드 검토 역할과 콘텐츠 제작 역할
- 확인한 위험: 입력에 없는 효능·후기·할인·성과를 만들거나 패키지 특징이 장면마다 바뀌는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

- 검증: 인물·제품·공간 일관성
- 과정별 확인 역할: 브랜드 검토 역할과 콘텐츠 제작 역할
