# M07-D02 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 콘텐츠 요청 Sheet–Notion 자동 등록
- 입력: 요청 ID, 채널, 목표, 콘텐츠 유형, 상태, 기획서 링크
- 기대 결과: 콘텐츠 트리거·매핑·Notion 등록·오류 수정 로그
- 주요 위험: 채널·목표 값 매핑 오류와 검토 전 콘텐츠의 운영 DB 등록
- 최종 확인 역할: 콘텐츠 자동화 소유 역할과 브랜드 DB 관리자 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 가상 Sheet 응답, 필드 매핑표, 실행 로그 기록
- 실제 정보 사용: 없음

- 수행: 콘텐츠 요청 자동화 흐름을 노드 맵으로 재구성
- 결과: n8n 워크플로우의 교육용 초안
- 검증: 입력 행
- 과정별 확인 역할: 콘텐츠 자동화 소유 역할과 브랜드 DB 관리자 역할
- 확인한 위험: 채널·목표 값 매핑 오류와 검토 전 콘텐츠의 운영 DB 등록
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
