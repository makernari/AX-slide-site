# M07-D02 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

제공된 콘텐츠 요청 Sheet를 n8n에서 읽고 채널·목표·콘텐츠 유형을 정규화해 Notion 콘텐츠 DB에 등록합니다.

## 네 차시

1. 콘텐츠 요청 흐름을 트리거–정규화–채널 분기–등록–게시 상태로 재구성합니다.
2. 제공 CSV를 읽고 채널·목표·콘텐츠 유형·핵심사실의 첫 입력을 확인합니다.
3. 열과 Notion 속성을 매핑하고 채널별 제작 큐와 브랜드 검수 상태를 등록합니다.
4. 잘못된 채널·누락 목표·유형·링크·DB 접근을 고치고 실행 로그를 비교합니다.

## 제출 결과물

- n8n 콘텐츠 요청 노드 맵
- Sheets–Notion 매핑표
- 채널 분기·오류 로그
- Apps Script–n8n 비교표

## 완료 기준

- [ ] 원자료의 필수값·허용값·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 오류 또는 누락 입력을 정상 입력과 분리함
- [ ] 브랜드 사실·채널·타깃·권리·성과 산식를 원본과 대조함
- [ ] 도구 접근이 없을 때 문서형 대체 결과를 완성함
