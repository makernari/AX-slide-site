# M07-D01 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 콘텐츠 제작 요청 자동 보고
- 입력: 채널, 목표, 타깃, 핵심 메시지, 콘텐츠 유형을 담은 비식별 폼 응답
- 기대 결과: 콘텐츠 요청 폼, 응답 Sheet, 요청 요약 Docs, 콘텐츠 포트폴리오 DB
- 주요 위험: 고객정보 과다 수집, 채널·목표 매핑 오류, 초안 링크 무단 공유
- 최종 확인 역할: 콘텐츠 운영 역할과 브랜드 검토 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 교육용 가상 폼 응답과 생성 문서 링크
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 콘텐츠 요청·고객 설문·캠페인 폼 제작
- 결과: Google Form의 교육용 초안
- 검증: 최소 수집
- 과정별 확인 역할: 콘텐츠 운영 역할과 브랜드 검토 역할
- 확인한 위험: 고객정보 과다 수집, 채널·목표 매핑 오류, 초안 링크 무단 공유
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 채널·목표·타깃별 응답 확인
- 결과: 응답 Sheet의 교육용 초안
- 검증: 열 이름 일치
- 과정별 확인 역할: 콘텐츠 운영 역할과 브랜드 검토 역할
- 확인한 위험: 고객정보 과다 수집, 채널·목표 매핑 오류, 초안 링크 무단 공유
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 결과: Apps Script 자동 보고서의 교육용 초안
- 검증: 생성 문서 내용
- 과정별 확인 역할: 콘텐츠 운영 역할과 브랜드 검토 역할

- 상태: 완료
