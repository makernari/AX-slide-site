# M07-D01 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

가상 캠페인 콘텐츠 요청을 구조화하고 응답 행을 기획 카드와 PDF로 변환해 Notion 콘텐츠 DB에 등록합니다.

## 네 차시

1. 채널·목표·타깃·사실·금지 표현 질문과 응답자 접근 범위를 설계합니다.
2. 응답 Sheet에서 복수 채널·필수 사실·마감일·위험 입력을 확인합니다.
3. 제공 코드를 수정해 기획 카드와 PDF를 만들고 설치형 제출 트리거를 연결합니다.
4. 채널·목표·상태·기획 링크를 Notion 콘텐츠 DB에 등록하고 공개 범위를 확인합니다.

## 제출 결과물

- 콘텐츠 요청 Form 설계표
- 응답 Sheet
- 기획 카드·PDF
- Notion 콘텐츠 DB 등록표

## 완료 기준

- [ ] 원자료의 필수값·허용값·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 오류 또는 누락 입력을 정상 입력과 분리함
- [ ] 브랜드 사실·채널·타깃·권리·성과 산식를 원본과 대조함
- [ ] 도구 접근이 없을 때 문서형 대체 결과를 완성함
