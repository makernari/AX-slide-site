# M05-D02 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 신제품 콘텐츠 기획회의 정리
- 입력: 핵심 메시지, 촬영 아이디어, 검토 일정, 게시 채널에 관한 화자별 발언
- 기대 결과: 아이디어·확정안·촬영·검토·게시 일정이 분리된 콘텐츠 회의록
- 주요 위험: 아이디어를 확정 캠페인으로 바꾸거나 게시 채널·일정을 만들어내는 오류
- 최종 확인 역할: 콘텐츠 기획 역할과 브랜드 검토 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 가상 회의 녹취와 발언 위치
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 가상 콘텐츠 기획회의 음성을 녹취하고 아이디어·촬영·게시 후보 표시
- 결과: 녹취록의 교육용 초안
- 검증: 결정과 제안의 분리
- 과정별 확인 역할: 콘텐츠 기획 역할과 브랜드 검토 역할
- 확인한 위험: 아이디어를 확정 캠페인으로 바꾸거나 게시 채널·일정을 만들어내는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

- 과정별 확인 역할: 콘텐츠 기획 역할과 브랜드 검토 역할
