# M08-D02 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

독립 실행되는 BLOOM BITE HTML 스타터의 파일 구조를 설명하게 하고 실시간 글자 수 기능 하나를 추가한 뒤 채널별 테스트와 변경 보고서를 완성합니다.

## 네 차시

1. ChatGPT·AI Studio·Codex 역할을 구분하고 제공 HTML을 작업 폴더에 복사합니다.
2. Codex에 HTML·CSS·JavaScript와 채널·금지표현 규칙 위치를 설명하게 합니다.
3. MK-C3 계약대로 실시간 글자 수 기능 하나만 추가하고 diff에서 변경 범위를 확인합니다.
4. 7개 테스트와 모바일 확인을 수행하고 교육 기준임을 밝힌 작업보고서를 작성합니다.

## 제출 결과물

- 파일 역할 설명
- 실시간 글자 수 기능 추가본
- 7개 채널 테스트 기록
- 변경 전후 작업보고서

## 완료 기준

- [ ] 원자료의 요구사항·근거ID·허용·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 정상·빈 값·이상·지시문 입력을 분리해 시험함
- [ ] 브랜드 사실·채널·타깃·금지 표현·검토 상태를 원본과 대조함
- [ ] 도구 접근이 없을 때 카드·HTML·문서형 대체 결과를 완성함
