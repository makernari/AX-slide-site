# M06-D02 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 NOVA-TEA 브랜드 소개 30초 쇼츠
- 입력: 브랜드 핵심 메시지, 제품 특징, SNS 타깃과 행동 요청
- 기대 결과: 브랜드 훅·핵심·마무리 대본, 채널용 자막, 음악 A/B 선택, 권리 기록
- 주요 위험: 효능·후기·할인을 만들어내거나 음악과 전환이 브랜드 톤을 해치는 오류
- 최종 확인 역할: 브랜드 매니저 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 직접 작성한 30~60초 대본과 권리 확인 기록
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 브랜드·상품·캠페인 주제와 대본 작성
- 결과: 완성형 쇼츠의 교육용 초안
- 검증: 첫 3초 훅
- 과정별 확인 역할: 브랜드 매니저 역할
- 확인한 위험: 효능·후기·할인을 만들어내거나 음악과 전환이 브랜드 톤을 해치는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 마케팅 콘텐츠 쇼츠 초안 제작
- 결과: 스크립트의 교육용 초안
- 검증: 자막 가독성
- 과정별 확인 역할: 브랜드 매니저 역할
- 확인한 위험: 효능·후기·할인을 만들어내거나 음악과 전환이 브랜드 톤을 해치는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 감성·역동·고급감 중 브랜드 영상 음악 선택
- 결과: 자막본의 교육용 초안
- 검증: 음량 균형
- 과정별 확인 역할: 브랜드 매니저 역할
- 확인한 위험: 효능·후기·할인을 만들어내거나 음악과 전환이 브랜드 톤을 해치는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 브랜드·캠페인 쇼츠 완성
- 결과: 음악·저작권 확인표의 교육용 초안
- 검증: 장면과 메시지 일치
- 과정별 확인 역할: 브랜드 매니저 역할
- 확인한 위험: 효능·후기·할인을 만들어내거나 음악과 전환이 브랜드 톤을 해치는 오류

## 최종 결과물 묶음

- 완성형 쇼츠: 완료 구조와 검증 메모 포함
- 스크립트: 완료 구조와 검증 메모 포함
- 자막본: 완료 구조와 검증 메모 포함
- 음악·저작권 확인표: 완료 구조와 검증 메모 포함

## 사람의 최종 확인

- 브랜드 사실·과장 표현·타깃·채널 맥락·저작권
