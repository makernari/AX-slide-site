# M06-D02 마케팅 시작 파일

> 기준일: 2026-08-08
> 단독 수강: 이 파일과 원자료만으로 시작 가능

## 과제

제품 사실과 팝업 CTA를 훅·사용 장면·행사 안내로 연결하고 음악 인상과 권리를 비교합니다.

## 사용할 원자료

- m06-d02-marketing-source-pack.md
- 먼저 원자료 ID와 확정·금지·한계를 표시합니다.

## 네 차시

1. 제품 사실을 훅–사용–CTA의 30초 대본으로 정리합니다.
2. Vrew 또는 문서형 대체표로 자막·제품 장면·CTA 시간을 검수합니다.
3. Suno 음악 후보의 브랜드 인상을 비교하고 모방·권리 위험을 기록합니다.
4. Vrew 또는 타임라인 보드에서 제품 일치·자막 안전 영역·음량을 점검합니다.

## 제출 결과물

- 30초 캠페인 대본
- 자막·CTA 타이밍표
- 음악 인상·권리표
- 9:16 캠페인 타임라인

## 시작 전 체크

- [ ] 실제 개인정보·내부 화면을 사용하지 않음
- [ ] 원자료 밖 수치·효능·정책을 만들지 않음
- [ ] 자동 생성한 글자·자막·출처를 사람이 확인함
- [ ] 브랜드 사실·과장 표현·채널 권리를 최종 결과에 기록함
