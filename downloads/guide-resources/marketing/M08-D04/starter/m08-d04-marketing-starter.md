# M08-D04 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

마케팅용 도구 카드 네 장으로 실행 순서를 설계하고, 승인 없는 게시·외부 업로드를 제외한 가상 에이전트 미션과 브랜드 보안 평가표를 완성합니다.

## 네 차시

1. API·Function Calling·MCP·에이전트를 주문·도구·실행자 비유로 비교하고 네 도구 카드를 읽습니다.
2. 브랜드 조회→콘텐츠 초안→검토→Notion 초안 등록 순서를 배열하고 승인 지점을 표시합니다.
3. 준비된 MCP 환경 또는 카드 시뮬레이션으로 MK-M1 미션과 호출 로그를 수행합니다.
4. 팩트·권리·인젝션·무단 등록·오류·중지 방법을 점검하고 브랜드 보안표를 완성합니다.

## 제출 결과물

- 마케팅 도구 카드
- MCP 콘텐츠 흐름도
- 가상 미션 호출 로그
- 브랜드·권한·승인 체크표

## 완료 기준

- [ ] 원자료의 요구사항·근거ID·허용·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 정상·빈 값·이상·지시문 입력을 분리해 시험함
- [ ] 브랜드 사실·채널·타깃·금지 표현·검토 상태를 원본과 대조함
- [ ] 도구 접근이 없을 때 카드·HTML·문서형 대체 결과를 완성함
