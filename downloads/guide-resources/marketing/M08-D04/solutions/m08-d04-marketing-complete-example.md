# M08-D04 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 브랜드 자료 조회–콘텐츠 초안–검토–Notion 등록 에이전트
- 입력: 가상 브랜드 자료 ID와 조회·초안·검토·등록 도구 카드
- 기대 결과: 브랜드 검토가 포함된 도구 순서, 등록 전 승인, 실행 로그와 중지 기준
- 주요 위험: 브랜드 검토 전 공개 등록하거나 외부 자료의 지시문·API 키를 실행 입력으로 사용하는 오류
- 최종 확인 역할: 브랜드 소유 역할과 콘텐츠 등록 승인 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 교육용 도구 카드, 가상 미션, 실행 로그
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 자료 조회·초안 생성·등록·검토 기능을 도구 카드로 정리
- 결과: MCP 도구 흐름도의 교육용 초안
- 검증: 최소 권한
- 과정별 확인 역할: 브랜드 소유 역할과 콘텐츠 등록 승인 역할
- 확인한 위험: 브랜드 검토 전 공개 등록하거나 외부 자료의 지시문·API 키를 실행 입력으로 사용하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
