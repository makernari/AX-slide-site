## 2. 권장 사용 순서

1. 시작 파일을 내려받는다.
2. 샘플 CSV로 반복 콘텐츠와 제작 단계를 분류한다.
3. 빈 템플릿 또는 시작 파일에 비식별 콘텐츠 경험을 기록한다.
4. 프롬프트 모음에서 해당 차시 프롬프트를 복사한다.
5. 완성 예시의 구조와 검토 방식을 참고하여 자신의 결과를 수정한다.

## 3. 수강생 배포 파일

모든 파일을 배포할 수 있다. 완성 예시는 특정 채널의 성공 공식을 제시하지 않으며, 목표·콘텐츠 역할·채널과 사람의 검토가 연결된 결과의 모양만 보여준다.

## 4. 강사용 파일

강사는 완성 예시와 프롬프트 모음을 시연 전에 열어 둔다. 계정 또는 Gem을 사용할 수 없는 수강생에게는 시작 파일과 정렬 템플릿으로 설계 문서형 대체 실습을 제공한다.

## 5. 파일별 주의사항

- Markdown 파일은 Google Docs에 내용을 복사하여 사용할 수 있다.
- CSV는 스프레드시트 프로그램 또는 텍스트 편집기로 열 수 있다.
- 채널 규격과 브랜드 기준은 실제 운영 자료가 확인된 경우에만 적용한다.
- AI 출력의 사실, 표현, 저작권, 채널 적합성은 사람이 최종 확인한다.

## 6. 보안 및 개인정보 안내

이 폴더의 자료는 모두 교육용 가상 사례다. 실제 고객정보, 캠페인 성과, 집행비, 미공개 브랜드 지침, 제휴 조건, 실제 후기, API 키를 추가하지 않는다.
