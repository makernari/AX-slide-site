# [M05-D01] 마케팅 Gemini 연결 앱과 @ 호출 실습

기준일: 2026-08-08

> 커리큘럼 핵심 보강. 필수 30분 + 선택 25분. 기존 과정 폴더·Docs·진단 Gem 결과를 대체하지 않습니다.

## 이 실습팩의 위치

- 커리큘럼 연결: Google 계정·Drive·Docs 기초 확인과 Gemini에서 연결 가능한 Google 앱 확인
- 학습 목적: 앱을 여러 개 오가며 찾던 정보를 대화에서 조회하고, 출처 화면에서 다시 확인하는 습관을 만듭니다.
- 기능·명칭 보정: @는 모든 서비스를 자동 연결하는 문법이 아닙니다. 현재 계정과 관리자 정책에서 표시되는 앱만 선택합니다.
- 이 문서는 강사용 상세 절차와 수강생 개인 Notion 정리를 연결하는 로컬 실습자료입니다.

## 시작 전 공통 규칙

1. 교육용 가상 자료 또는 본인이 공개해도 되는 자료만 사용합니다.
2. 기능·앱·모델이 화면에 없으면 현재 상태를 기록하고 대체 실습으로 이동합니다.
3. 생성·등록·공유·취소·삭제 전에는 대상 이름을 다시 읽습니다.
4. AI 응답의 링크·출처·수치·한글·인물·제품 대응을 사람이 확인합니다.
5. 결과 전체를 공용 Notion에 붙이지 않고 개인 Notion에 최소 기록만 남깁니다.

## 실습 1. 연결 앱 준비 상태 확인

- 구분: 필수
- 권장 시간: 7분
- 준비 입력: 수업용 Google 계정과 빈 기록표
- 완료 결과: 연결 가능·불가·관리자 확인 3상태 표

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. Gemini에 수업용 계정으로 로그인한 뒤 새 대화를 열고 `@`만 입력합니다.
4. 화면에 ‘앱’ 또는 ‘연결 앱’ 항목이 실제로 보일 때만 열어 Gmail·Drive·Calendar의 현재 상태를 적습니다. 관리자 제한 표시는 임의로 바꾸지 않습니다.
5. 표시된 앱 하나를 선택해 교육용 키워드로 조회하고, 표시되지 않은 앱은 `현재 계정에서 확인 필요`로 남깁니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
새 대화에서 @를 입력했을 때 현재 선택 가능한 앱 이름만 적어 줘. 선택되지 않는 앱은 추측하지 말고 ‘현재 계정에서 확인 필요’로 남겨 줘.
```

### 완료 확인

- [ ] 같은 Workspace 계정으로 로그인했고 실제로 표시된 앱만 기록했는가?
- [ ] 완료 결과를 다시 열 수 있음: **연결 가능·불가·관리자 확인 3상태 표**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

연결 설정을 바꾸지 않고 제공된 예시 화면에서 상태를 분류합니다.

## 실습 2. Gmail 이번 주 메일 요약

- 구분: 필수
- 권장 시간: 8분
- 준비 입력: 수업용 계정의 콘텐츠 요청·촬영 일정·캠페인 자료 가상 메일 또는 제공 CSV
- 완료 결과: 메일 요약표와 원문 재확인 1건

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.

5. 그 행의 원문 링크를 열어 보낸 역할·요청·기한이 실제 메일과 같은지 확인하고 기록표를 수정합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.

- 완료 결과: 실습 문서 후보와 원문 재열기 기록
