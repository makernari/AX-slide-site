# M06-D03 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 숏폼 콘텐츠 운영 사례 리서치와 카피 검토 GPT
- 입력: 날짜·출처 유형이 다른 교육용 시장·브랜드 사례 세 건
- 기대 결과: 시장 사례 보고서와 브랜드 카피 검토 GPT 명세·테스트표
- 주요 위험: 사례의 상관관계를 성과 원인으로 단정하거나 브랜드 사실을 임의 생성하는 오류
- 최종 확인 역할: 마케팅 전략 역할과 브랜드 검토 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 날짜와 출처 유형이 표시된 교육용 자료 묶음
- 실제 정보 사용: 없음

- 결과: 리서치 보고서의 교육용 초안
- 검증: 질문 범위
- 과정별 확인 역할: 마케팅 전략 역할과 브랜드 검토 역할
- 확인한 위험: 사례의 상관관계를 성과 원인으로 단정하거나 브랜드 사실을 임의 생성하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
