# M06-D03 마케팅 시작 파일

> 기준일: 2026-08-08
> 단독 수강: 이 파일과 원자료만으로 시작 가능

## 과제

가상 제품 자료와 채널 반응을 구분해 캠페인 방향 보고서와 과장 표현을 막는 GPT를 설계합니다.

## 사용할 원자료

- m06-d03-marketing-source-pack.md
- 먼저 원자료 ID와 확정·금지·한계를 표시합니다.

## 네 차시

1. 연구 질문·제품·채널 출처 범위를 Project 구조표로 정리합니다.
2. Deep Research 또는 수동 근거표로 날짜·공식성·표본 한계를 검토합니다.
3. 제품 사실·과장·채널·CTA를 검토하는 GPT 명세를 작성합니다.
4. 정상·애매·자료 밖·역할 밖·개인정보 질문으로 테스트하고 수정합니다.

## 제출 결과물

- 캠페인 리서치 보고서
- ChatGPT Project 구조표
- 카피 검토 GPT 명세
- 5유형 압박 테스트표

## 시작 전 체크

- [ ] 실제 개인정보·내부 화면을 사용하지 않음
- [ ] 원자료 밖 수치·효능·정책을 만들지 않음
- [ ] 자동 생성한 글자·자막·출처를 사람이 확인함
- [ ] 브랜드 사실·과장 표현·채널 권리를 최종 결과에 기록함
