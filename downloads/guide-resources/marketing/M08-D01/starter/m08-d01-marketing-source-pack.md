# M08-D01 마케팅 원자료 · BLOOM BITE 브랜드 톤 점검기

> 교육용 가상 브랜드 BLOOM BITE · 실제 캠페인·고객정보 없음 · 2026-08-08 검수

## MK-A1 · 공통 체험 앱

- 제공된 샘플 이미지만 사용하는 손금분석 엔터테인먼트 앱을 생성한다.
- ‘오락용이며 성격·건강·미래를 판단하지 않습니다’를 결과 상단에 표시한다.
- 실제 고객 사진·얼굴·신분증·건강정보를 넣지 않는다.

## MK-A2 · 가상 브랜드 팩트

- 브랜드: BLOOM BITE
- 제품: Citrus Spark 250ml
- 확인된 사실: 무카페인, 2026년 8월 가상 출시
- 톤: 따뜻하고 구체적이며 짧은 문장
- 금지: 무조건, 최고, 100%, 치료·예방 표현, 확인되지 않은 수치

## MK-A3 · 직무 앱 요구사항

| 구분 | 요구사항 |
|---|---|
| 목적 | 카피가 채널·타깃·브랜드 톤·팩트·금지표현을 지키는지 점검 |
| 입력 | 채널, 가상 타깃, 캠페인 목표, 카피 600자 이내 |
| 처리 | 팩트 일치·금지표현·톤·행동유도문 확인 |
| 출력 | 적합도, 근거, 위험 표현, 대체 카피, 사람 검토 항목 |
| 금지 | 실제 고객정보, 성과 보장, 원자료 밖 제품 사실 |

## MK-A4 · AI Studio Build 요청

BLOOM BITE 브랜드 톤 점검기 웹 앱을 만들어 주세요. 채널·가상 타깃·캠페인 목표·카피를 입력받고 브랜드 팩트와 금지표현을 대조하세요. 출력은 적합도, 근거, 위험 표현, 대체 카피, 사람 검토 항목 순서로 보여 주세요. 원자료 밖 제품 사실이나 성과를 만들지 말고 빈 입력과 600자 초과를 막아 주세요.

| ID | 입력 | 기대 결과 |
|---|---|---|

## MK-A6 · 공유 전 확인

- 비밀값·실제 고객정보·비공개 캠페인 자료가 없다.
- 대체 카피도 브랜드 팩트와 금지표현을 다시 검사한다.
- 공유 사용자의 입력 저장·비용·사용 한도는 현재 계정 안내에서 확인한다.
- 공유 링크 없이 요구사항·테스트표만 제출하는 대체 경로를 제공한다.
