# M08-D01 마케팅 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

제공 샘플 이미지로 오락용 손금분석 앱을 체험한 뒤, 구조를 BLOOM BITE 브랜드 톤 점검기로 바꾸고 채널·타깃·금지표현을 시험합니다.

## 네 차시

1. 요구사항–입력–처리–출력–테스트 구조와 오락용 앱의 면책 범위를 정합니다.
2. 제공 샘플 이미지로 손금분석 앱을 생성하고 제목·버튼·결과 문구를 수정합니다.
3. 같은 구조를 브랜드 톤 점검기로 리믹스하고 브랜드 팩트와 금지표현을 연결합니다.
4. 정상·빈 입력·과장·팩트 오류·지시문 입력을 시험하고 공유 안내를 작성합니다.

## 제출 결과물

- 오락용 앱 수정 기록
- 브랜드 톤 앱 요구사항
- 채널별 테스트표
- 공유·브랜드 검토 안내

## 완료 기준

- [ ] 원자료의 요구사항·근거ID·허용·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 정상·빈 값·이상·지시문 입력을 분리해 시험함
- [ ] 브랜드 사실·채널·타깃·금지 표현·검토 상태를 원본과 대조함
- [ ] 도구 접근이 없을 때 카드·HTML·문서형 대체 결과를 완성함
