# M08-D01 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 브랜드 카피 점검 앱
- 입력: 목표·타깃·핵심 메시지·채널이 일부 빠진 가상 브랜드 카피
- 기대 결과: 누락과 과장 위험을 표시하고 입력을 초기화할 수 있는 콘텐츠 앱과 테스트표
- 주요 위험: 브랜드 사실·성과·후기를 만들어내거나 특정 채널 맥락을 무시하는 오류
- 최종 확인 역할: 브랜드 검토 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 교육용 샘플 입력과 요구사항·테스트 기록
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 콘텐츠형 앱으로 바꿀 수 있는 입력·출력 아이디어 정리
- 결과: 재미 앱 1종의 교육용 초안
- 검증: 입력과 출력의 연결
- 과정별 확인 역할: 브랜드 검토 역할
- 확인한 위험: 브랜드 사실·성과·후기를 만들어내거나 특정 채널 맥락을 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 샘플 이미지로 체험 앱 실행·수정
- 결과: 직무형 앱 1종의 교육용 초안
- 검증: 한 번에 한 변경
- 과정별 확인 역할: 브랜드 검토 역할
- 확인한 위험: 브랜드 사실·성과·후기를 만들어내거나 특정 채널 맥락을 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 광고 카피 평가·SNS 개선·브랜드 톤 점검 앱 제작
- 결과: 요구사항 프롬프트와 테스트 기록의 교육용 초안
- 검증: 빈·이상·민감 입력
- 과정별 확인 역할: 브랜드 검토 역할
- 확인한 위험: 브랜드 사실·성과·후기를 만들어내거나 특정 채널 맥락을 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 마케팅 앱 테스트와 공유 링크 정리
- 결과: 요구사항 프롬프트와 테스트 기록의 교육용 초안
- 검증: 면책 안내
- 과정별 확인 역할: 브랜드 검토 역할
- 확인한 위험: 브랜드 사실·성과·후기를 만들어내거나 특정 채널 맥락을 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 최종 결과물 묶음

- 재미 앱 1종: 완료 구조와 검증 메모 포함
- 직무형 앱 1종: 완료 구조와 검증 메모 포함
- 요구사항 프롬프트와 테스트 기록: 완료 구조와 검증 메모 포함

## 사람의 최종 확인

- 브랜드 사실·과장 표현·타깃·채널 맥락·저작권
- 저장 위치와 공유 범위
- 실제 운영 자료로 교체하기 전 보안·권리 재검토
