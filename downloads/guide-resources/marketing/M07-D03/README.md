# M07-D03 마케팅 실습자료

기준일: 2026-08-08

## 단독·연속 수강 원칙

- 이 과정만 수강해도 원자료·샘플·프롬프트·템플릿·완성 예시로 네 차시를 끝낼 수 있습니다.
- 오전·오후를 모두 수강해도 입력 데이터·업무 규칙·오류·최종 산출물을 반복하지 않습니다.
- 오전 경영지원과 달리 채널·콘텐츠 유형·가중 CTR·전환·CPA와 인과 과장이 핵심입니다.

## 오늘의 과제

12개 가상 콘텐츠의 노출·클릭·전환·비용을 검산하고 채널 성과와 한계를 분리해 마케팅 리포트를 작성합니다.

## 파일 구성

- starter/m07-d03-marketing-source-pack.md: 직무별 교육 원자료
- starter/m07-d03-marketing-starter.md: 차시별 시작 파일
- samples/m07-d03-marketing-samples.csv: 복사 가능한 가상 입력 데이터
- templates/m07-d03-marketing-practice-template.md: 빈 결과물 틀
- templates/m07-d03-marketing-prompt-pack.txt: 복사 프롬프트
- solutions/m07-d03-marketing-complete-example.md: 완성 예시

## 안전 기준

- 실제 개인정보·조직 내부 데이터·자격증명·API 키를 넣지 않습니다.
- 기능·메뉴·요금·한도는 수업 계정에서 확인합니다.
- 브랜드 사실·채널·타깃·권리·성과 산식를 사람이 최종 확인합니다.
