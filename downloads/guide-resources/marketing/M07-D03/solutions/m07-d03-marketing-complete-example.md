# M07-D03 마케팅 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 리서치·기획·콘텐츠·채널 운영을 개선하려는 재직자
- 대표 사례: 가상 채널별 콘텐츠 성과 데이터 분석
- 입력: 채널·콘텐츠 유형·기간별 조회·클릭·전환·비용
- 기대 결과: 직접 계산한 핵심 수치·차트와 사실–해석–가설이 분리된 분석 리포트
- 주요 위험: 조회 수 증가를 전환 원인으로 단정하거나 채널 규모 차이를 무시하는 오류
- 최종 확인 역할: 성과 분석 역할과 캠페인 책임 역할
- 장면: 교육용 가상 브랜드의 콘텐츠 업무
- 근거: 제공된 숫자형 샘플 CSV와 직접 계산한 합계·평균
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: SNS 게시물·광고·고객 설문 중 간단 데이터 확인
- 결과: Google Sheet의 교육용 초안
- 검증: 합계·평균 재계산
- 과정별 확인 역할: 성과 분석 역할과 캠페인 책임 역할
- 확인한 위험: 조회 수 증가를 전환 원인으로 단정하거나 채널 규모 차이를 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 채널·콘텐츠·기간별 주요 수치와 차트 작성
- 결과: 핵심 차트 1~2개의 교육용 초안
- 검증: 차트와 질문의 대응
- 과정별 확인 역할: 성과 분석 역할과 캠페인 책임 역할
- 확인한 위험: 조회 수 증가를 전환 원인으로 단정하거나 채널 규모 차이를 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 콘텐츠·성과 데이터 분석과 개선 아이디어 생성
- 결과: Google Docs 1페이지 분석 보고서의 교육용 초안
- 검증: 사실·해석·가설 구분
- 과정별 확인 역할: 성과 분석 역할과 캠페인 책임 역할
- 확인한 위험: 조회 수 증가를 전환 원인으로 단정하거나 채널 규모 차이를 무시하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 마케팅 1페이지 분석 리포트 작성
- 결과: Google Docs 1페이지 분석 보고서의 교육용 초안
- 검증: 추가 질문
- 과정별 확인 역할: 성과 분석 역할과 캠페인 책임 역할

- 핵심 차트 1~2개: 완료 구조와 검증 메모 포함
