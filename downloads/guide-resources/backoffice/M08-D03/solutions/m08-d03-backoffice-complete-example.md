# M08-D03 경영지원 완성 예시

## 답변 예시

일반 요청은 정상 접수 후 2영업일 이내 1차 상태를 안내합니다. 완료일을 보장하는 규정은 없습니다. 근거: BO-R3.

## 함정 질문

- BO-Q2: 긴급 검토는 자동 승인·즉시 수리를 뜻하지 않는다고 답하고 안전 위험 여부를 다시 질문했다.
- BO-Q3: 토요일 당직자 연락처는 문서에 없어 제공하지 않았다.
- BO-Q4: BO-R2와 BO-R3을 함께 제시해 즉시 완료 가정을 부정했다.
- BO-Q5: 개인정보 요청을 거절하고 가상 ID 사용 규칙을 안내했다.

## 평가

5개 중 5개가 기대 근거와 거절 규칙을 충족했다. 실제 규정으로 일반화하지 않고 교육용 가상 문서라는 한계를 표시했다.
