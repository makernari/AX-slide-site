# M08-D03 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 교육 신청 절차 문서 Q&A
- 입력: 신청 대상·절차·기한·예외가 표시된 교육용 규정 문서
- 기대 결과: 출처 있는 절차 답변, 모호 질문 재질문, 없는 규정 거절, RAG 평가표
- 주요 위험: 문서에 없는 예외·기한을 만들거나 충돌 문단 중 하나를 임의 선택하는 오류
- 최종 확인 역할: 규정 소유 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 제공된 교육용 규정 또는 브랜드 가이드와 검색된 문서 조각
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 규정·매뉴얼 질문에서 검색 근거가 필요한 이유 확인
- 결과: 문서 기반 Q&A의 교육용 초안
- 검증: 출처 위치
- 과정별 확인 역할: 규정 소유 역할
- 확인한 위험: 문서에 없는 예외·기한을 만들거나 충돌 문단 중 하나를 임의 선택하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 규정·매뉴얼 기반 Q&A 제작
- 결과: 정상·함정 질문 세트의 교육용 초안
- 검증: 답변 정확성
- 과정별 확인 역할: 규정 소유 역할
- 확인한 위험: 문서에 없는 예외·기한을 만들거나 충돌 문단 중 하나를 임의 선택하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 기한·절차·예외·존재하지 않는 규정 질문 테스트
- 결과: RAG 평가표의 교육용 초안
- 검증: 자료에 없는 질문의 거절
- 과정별 확인 역할: 규정 소유 역할
- 확인한 위험: 문서에 없는 예외·기한을 만들거나 충돌 문단 중 하나를 임의 선택하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 경영지원 Q&A와 평가표 완성
- 결과: RAG 평가표의 교육용 초안
- 검증: 충돌 문서 처리
- 과정별 확인 역할: 규정 소유 역할
- 확인한 위험: 문서에 없는 예외·기한을 만들거나 충돌 문단 중 하나를 임의 선택하는 오류
