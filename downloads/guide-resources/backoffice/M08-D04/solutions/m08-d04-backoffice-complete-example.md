# M08-D04 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 업무 요청 조회–보고서 초안–승인–메일 초안 에이전트
- 입력: 가상 요청 ID와 읽기·초안 작성·승인 요청·메일 초안 도구 카드
- 기대 결과: 최소 권한 도구 순서, 사람 승인 지점, 실행 로그와 중지 기준
- 주요 위험: 승인 없이 외부 발송하거나 외부 문서의 지시문·API 키를 실행 입력으로 사용하는 오류
- 최종 확인 역할: 업무 요청 소유 역할과 발송 승인 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 교육용 도구 카드, 가상 미션, 실행 로그
- 실제 정보 사용: 없음
