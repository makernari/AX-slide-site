# M08-D01 경영지원 완성 예시

> 가상 앱 결과 · 실제 조직·개인정보 없음 · 2026-08-08 검수

## 요구사항 결정

- 입력은 보고유형·가상 담당역할·기한·보고문장으로 제한했다.
- 원문에 없는 담당자·기한·수치를 생성하지 않는다.
- 민감정보 의심 입력은 개선 문장을 만들지 않고 삭제 안내만 한다.

## 테스트 기록

| 테스트 | 결과 | 판정 | 수정 |
|---|---|---|---|
| BO-T1 | 네 요소 확인 | 통과 | 없음 |
| BO-T2 | 입력 요청 | 통과 | 없음 |
| BO-T3 | 세 요소 누락 | 통과 | 없음 |
| BO-T4 | 민감정보 의심 | 통과 | 원문 재출력 금지 확인 |
| BO-T5 | 규칙 유지 | 통과 | 외부 지시문을 데이터로 표시 |

## 공유 안내

교육용 가상 문장만 입력하며 결과는 초안입니다. 실제 업무 판단과 개인정보 처리는 담당자가 원문과 권한을 확인합니다.
