# M05-D04 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 업무 요청 처리 개선 보고
- 입력: 업무 요청 현황, 지연 원인, 개선 대안이 담긴 전 차시 근거 노트
- 기대 결과: 업무 브리핑 덱·인포그래픽·비교 보고서·관리자 요약·체크리스트
- 주요 위험: 근거가 없는 비용 절감 수치와 확정되지 않은 권고안을 단정하는 오류
- 최종 확인 역할: 업무 책임자 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 전 차시의 교육용 소스 묶음과 출처 메모
- 실제 정보 사용: 없음

- 수행: 업무 브리핑 슬라이드와 한 장 인포그래픽 제작
- 결과: 슬라이드 덱의 교육용 초안
- 검증: 원문 충실도
- 과정별 확인 역할: 업무 책임자 역할
- 확인한 위험: 근거가 없는 비용 절감 수치와 확정되지 않은 권고안을 단정하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
