# [M05-D02] 경영지원 기본 Gem 체험·직무 Gem 제작·공유 실습

기준일: 2026-08-08

> 커리큘럼 핵심 보강. 4차시 Gem 제작·검증 50분 안에서 운영. 영어·생활습관 Gem은 빠른 학습자 선택입니다.

## 이 실습팩의 위치

- 커리큘럼 연결: 검증된 회의록 프롬프트를 Gem 지침으로 저장하고 정상·모호·누락 입력으로 반복 테스트
- 학습 목적: 매번 긴 프롬프트를 다시 쓰지 않고 역할·작업·맥락·출력 형식을 재사용 가능한 AI 비서로 만듭니다.
- 기능·명칭 보정: 기존 Gem과 Google Labs 기반 미니앱형 Gem은 데이터 처리와 공유 방식이 다르므로 이번 핵심은 일반 맞춤 Gem입니다.
- 이 문서는 강사용 상세 절차와 수강생 개인 Notion 정리를 연결하는 로컬 실습자료입니다.

## 시작 전 공통 규칙

1. 교육용 가상 자료 또는 본인이 공개해도 되는 자료만 사용합니다.
2. 기능·앱·모델이 화면에 없으면 현재 상태를 기록하고 대체 실습으로 이동합니다.
3. 생성·등록·공유·취소·삭제 전에는 대상 이름을 다시 읽습니다.
4. AI 응답의 링크·출처·수치·한글·인물·제품 대응을 사람이 확인합니다.
5. 결과 전체를 공용 Notion에 붙이지 않고 개인 Notion에 최소 기록만 남깁니다.

## 실습 1. 현재 보이는 기본 Gem 1개 체험

- 구분: 필수
- 권장 시간: 5분
- 준비 입력: 개인정보 없는 짧은 교육용 문장
- 완료 결과: 기본 Gem 결과와 일반 채팅 차이 1줄

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. Gem 목록을 열고 현재 계정에 실제 표시된 기본 Gem 중 한 개를 고릅니다. 특정 기본 Gem 이름이 없으면 다른 항목을 선택합니다.
4. 같은 교육용 질문을 기본 Gem과 일반 채팅에 각각 입력합니다.
5. 역할 유지·질문 방식·출력 구조의 차이를 한 줄씩 비교합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
이 문장을 네가 맡은 역할에 맞게 처리해 줘. 결과의 형식과 말투가 일반 채팅과 어떻게 다른지도 한 줄로 설명해 줘.
```

### 완료 확인

- [ ] 화면에 실제로 보이는 기본 Gem만 사용했는가?
- [ ] 완료 결과를 다시 열 수 있음: **기본 Gem 결과와 일반 채팅 차이 1줄**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

강사가 제공한 기본 Gem 결과 예시 두 개를 비교합니다.

## 실습 7. 생활습관 코치 Gem

- 구분: 선택
- 권장 시간: 10분
- 준비 입력: 수면·물 마시기·걷기 같은 가상 습관 카드
- 완료 결과: 비의료 생활습관 Gem과 안전 문구

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. 생활습관 Gem 지침 첫 줄에 진단·치료·약물 조언을 하지 않는다고 명시합니다.
4. 가상의 수면 또는 스트레칭 습관을 입력해 작은 목표 한 개와 점검 질문이 나오는지 시험합니다.
5. 의학적 판단이 나오면 결과를 사용하지 않고 지침에 전문가 상담 안내와 작성 중지 조건을 추가합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
의학적 진단이나 치료 조언을 하지 않는 생활습관 성찰 Gem 지침을 작성해 줘. 오늘의 습관 체크→작은 목표 한 개→실행 방해 요인→내일 점검 질문 순서로 진행해 줘.
```

### 완료 확인

- [ ] 질병·약물·식이 치료를 판단하지 않고 전문 상담 경계를 표시했는가?
- [ ] 완료 결과를 다시 열 수 있음: **비의료 생활습관 Gem과 안전 문구**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

가상 습관 카드에 질문 네 개만 직접 적습니다.

## 공통 안전 확인

- [ ] 공유된 Gem의 지침과 업로드 파일은 접근 권한이 있는 사용자에게 보일 수 있습니다.
- [ ] 편집 권한은 지침·파일 변경과 삭제 권한을 포함할 수 있으므로 실습은 보기 권한을 기본으로 합니다.
- [ ] 건강 관련 Gem은 생활습관 성찰까지만 하며 진단·치료·약물 조언을 하지 않습니다.
- [ ] 영어 학습 Gem에는 실제 학습자 성적·연락처를 넣지 않습니다.
