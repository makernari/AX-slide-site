# M05-D02 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 월간 운영회의 정리
- 입력: 교육 일정, 자료 제출, 시설 점검에 관한 화자별 발언
- 기대 결과: 결정·미확정·담당자·기한이 분리된 회의록과 액션 아이템
- 주요 위험: 제안 내용을 확정 사항으로 기록하거나 담당자·기한을 추측하는 오류
- 최종 확인 역할: 회의 주관 역할과 각 액션 아이템 담당 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 가상 회의 녹취와 발언 위치
- 실제 정보 사용: 없음

- 수행: 가상 업무회의 음성을 녹취하고 화자·안건·결정 후보 표시
- 결과: 녹취록의 교육용 초안
- 검증: 결정과 제안의 분리
- 과정별 확인 역할: 회의 주관 역할과 각 액션 아이템 담당 역할
- 확인한 위험: 제안 내용을 확정 사항으로 기록하거나 담당자·기한을 추측하는 오류

- 상태: 완료
