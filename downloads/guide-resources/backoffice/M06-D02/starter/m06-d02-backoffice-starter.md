# M06-D02 경영지원 시작 파일

> 기준일: 2026-08-08
> 단독 수강: 이 파일과 원자료만으로 시작 가능

## 과제

확정된 전자결재 점검 3단계를 대본·자막·음악·세로 타임라인으로 조합합니다.

## 사용할 원자료

- m06-d02-backoffice-source-pack.md
- 먼저 원자료 ID와 확정·금지·한계를 표시합니다.

## 네 차시

1. 확정 절차를 훅–3단계–마무리의 35초 대본으로 정리합니다.
2. Vrew 또는 문서형 대체표로 자막·장면 분할과 오타를 검수합니다.
3. Suno 음악 후보의 분위기를 비교하고 권리 조건을 기록합니다.
4. Vrew 또는 타임라인 보드에서 음량·자막·전환을 최종 점검합니다.

## 제출 결과물

- 35초 대본
- 자막·타이밍표
- 음악 비교·권리표
- 9:16 편집 타임라인

## 시작 전 체크

- [ ] 실제 개인정보·내부 화면을 사용하지 않음
- [ ] 원자료 밖 수치·효능·정책을 만들지 않음
- [ ] 자동 생성한 글자·자막·출처를 사람이 확인함
- [ ] 확정 정보·내부 승인·권리 조건를 최종 결과에 기록함
