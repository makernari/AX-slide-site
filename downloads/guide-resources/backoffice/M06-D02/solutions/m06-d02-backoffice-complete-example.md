# M06-D02 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 전산 요청 작성법 30초 쇼츠
- 입력: 좋은 요청의 네 요소와 교육용 화면 설명
- 기대 결과: 훅–핵심–마무리 대본, 읽기 쉬운 자막, 신뢰감 있는 음악 선택, 권리 기록
- 주요 위험: 업무 절차보다 효과음·전환이 앞서거나 실제 시스템 화면이 노출되는 오류
- 최종 확인 역할: 업무 교육 담당 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 직접 작성한 30~60초 대본과 권리 확인 기록
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 업무 팁·교육 안내·서비스 소개 주제와 대본 작성
- 결과: 완성형 쇼츠의 교육용 초안
- 검증: 첫 3초 훅
- 과정별 확인 역할: 업무 교육 담당 역할
- 확인한 위험: 업무 절차보다 효과음·전환이 앞서거나 실제 시스템 화면이 노출되는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 결과: 스크립트의 교육용 초안
- 검증: 자막 가독성
- 과정별 확인 역할: 업무 교육 담당 역할
- 확인한 위험: 업무 절차보다 효과음·전환이 앞서거나 실제 시스템 화면이 노출되는 오류

## 3차시 완성 상태

- 검증: 음량 균형

- 상태: 완료

## 4차시 완성 상태

- 결과: 음악·저작권 확인표의 교육용 초안
