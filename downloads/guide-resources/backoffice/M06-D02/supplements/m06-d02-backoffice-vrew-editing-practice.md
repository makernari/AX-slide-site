# [M06-D02] 경영지원 Flow 클립→Vrew 최종 편집 실습

기준일: 2026-08-08

> 운영 업데이트. 실제 최종 편집은 Vrew에서 완료합니다. 별도 편집 도구 계정이나 설치는 실습 완료 조건이 아닙니다.

## 최신 확인 카드

- Vrew는 영상 불러오기→자동 전사/자막→텍스트 기반 편집→내보내기 흐름을 사용합니다. 무료 플랜의 현재 표시 범위만 사용합니다.
- 별도 편집 도구는 사용하지 않고 Vrew에서 편집·내보내기를 완료합니다.
- 화면에 기능이 없거나 크레딧이 부족하면 HTML 예시·캐릭터 시트·스토리보드·타임라인으로 같은 완료 상태를 만듭니다.

## 공통 안전선

- 실존 인물은 본인 또는 명시적 동의가 있을 때만 사용하며 기본 실습은 가상 인물입니다.
- 실제 회사·기관·고객 정보, 성과 수치, 로고, 자격증명, API 키를 넣지 않습니다.
- AI 결과의 얼굴·손·텍스트·제품 수·장면 연결을 사람이 확인합니다.
- 생성 결과를 실제 사건·제품 성능·착용감·업무 완료의 증거로 사용하지 않습니다.

## 실습 1. Flow 인계 폴더 검수

- 권장 시간: 10분
- 준비: M06-D01 선택 클립 3개·캐릭터 시트·권리 기록
- 완료 결과: 편집에 사용할 클립 3개와 인계 체크표

### 초보자 화면 행동

1. 파일명이 01·02·03 순서인지 확인합니다.
2. 각 클립을 끝까지 재생해 검은 프레임·왜곡·음성 유무를 기록합니다.
3. Vrew에는 선택본만 가져오고 생성 실패본은 별도 폴더로 옮깁니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.

### 복사해서 쓰는 프롬프트

```text

2. AI 생성 클립임을 숨기거나 SynthID를 제거하지 않고 필요한 고지 문구를 확인합니다.
3. 소리 켬·끔 두 번 재생해 자막만으로도 이해되는지 확인합니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.

첫 화면 제목과 마지막 CTA를 각각 12자 안팎으로 제안해 줘. 주제: 가상 사내 안전교육 안내 영상. 반드시 ‘교육용 가상 예시’를 포함하고 실제 성과처럼 보이는 표현은 제외해 줘.
```

## 실습 10. MP4·자막·편집 기록 내보내기

- 권장 시간: 15분
- 준비: 최종 검수된 Vrew 프로젝트
- 완료 결과: 재생 확인된 MP4와 자막·프롬프트·권리 기록 묶음

### 초보자 화면 행동

1. 현재 무료 플랜 화면에 실제 표시되는 내보내기 규격을 확인하고 MP4를 저장합니다.
2. SRT 또는 텍스트 내보내기가 보이면 함께 저장하고, 없으면 검수 대본을 TXT로 보관합니다.
3. MP4를 폴더 밖에서 다시 재생해 화면·소리·자막·길이를 확인하고 제출 체크를 완료합니다.
4. 첫 결과를 저장하고 원본·기준표와 대조해 오류 한 개만 수정합니다.
5. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·파일 링크만 남깁니다.

### 복사해서 쓰는 프롬프트

```text
최종 제출 목록을 MP4｜자막 파일 또는 검수 대본｜캐릭터 시트｜프롬프트｜권리 로그｜사람 수정 기록 순서로 만들어 줘.
```

### 완료 확인

- [ ] 내보낸 파일을 다시 열었고 무료 플랜 범위를 추측하지 않았는가?
- [ ] 완료 결과를 다시 열 수 있음: **재생 확인된 MP4와 자막·프롬프트·권리 기록 묶음**
- [ ] 실제 개인정보·내부자료·권리 불명 자료·API 키가 없음

### 막힐 때

프로젝트 화면 캡처·검수 대본·타임라인 HTML로 제출합니다.
