# [M05-D03] 경영지원 NotebookLM 소스→마인드맵→오디오→활용 실습

기준일: 2026-08-08

> 커리큘럼 핵심 보강. 기존 4차시 흐름을 그대로 세분화합니다. 외국어 영상 전체 대본 활용은 강사 소유·허가 영상에만 수행합니다.

## 이 실습팩의 위치

- 커리큘럼 연결: NotebookLM에서 공개 YouTube·PDF·웹 자료를 소스로 추가하고 마인드맵·학습문제·Audio Overview 생성
- 학습 목적: 내가 선택한 자료 안에서만 근거를 찾고, 같은 소스를 여러 학습 결과로 변환합니다.
- 기능·명칭 보정: NotebookLM의 YouTube 소스는 공개 영상 중 자막이 있는 영상의 텍스트 대본을 가져옵니다. 영상 자체와 화면 이미지를 가져오는 실습이 아닙니다.
- 이 문서는 강사용 상세 절차와 수강생 개인 Notion 정리를 연결하는 로컬 실습자료입니다.

## 시작 전 공통 규칙

1. 교육용 가상 자료 또는 본인이 공개해도 되는 자료만 사용합니다.
2. 기능·앱·모델이 화면에 없으면 현재 상태를 기록하고 대체 실습으로 이동합니다.
3. 생성·등록·공유·취소·삭제 전에는 대상 이름을 다시 읽습니다.
4. AI 응답의 링크·출처·수치·한글·인물·제품 대응을 사람이 확인합니다.
5. 결과 전체를 공용 Notion에 붙이지 않고 개인 Notion에 최소 기록만 남깁니다.

## 실습 1. 소스 권리·형식 점검

- 구분: 필수
- 권장 시간: 10분
- 준비 입력: 업무 절차·정책·교육자료 공개 PDF·웹·강사 소유 영상
- 완료 결과: 소스 3개와 권리·사용 범위 표

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. 새 Notebook을 만들기 전에 `notebook-source-rights-checklist.md`에 소유·허가·공개·자막 여부를 적습니다.
4. 소스 추가 화면에 실제 표시된 형식만 사용해 PDF·웹·강사 소유 자막 영상 중 두세 개를 등록합니다.
5. 등록 후 소스 제목과 가져온 범위를 확인하고 실패한 소스는 대체 PDF 또는 강사 제공 대본으로 바꿉니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
이 소스 목록을 공개·강사 소유·사용 허가·확인 필요로 분류하고, 전체 대본·번역·재게시 가능 범위를 표로 정리해 줘.
```

### 완료 확인

- [ ] 출처 제목·작성자/채널·URL·확인일·사용 범위를 기록했는가?
- [ ] 완료 결과를 다시 열 수 있음: **소스 3개와 권리·사용 범위 표**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

제공된 source-rights-checklist.md로 소스를 분류합니다.

## 실습 2. 마인드맵으로 큰 구조 확인

- 구분: 필수
- 권장 시간: 15분
- 준비 입력: 등록한 소스 2~3개
- 완료 결과: 핵심·하위·연결·충돌 노드가 있는 마인드맵

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. Studio 영역에 Mind Map이 실제로 보이면 등록 소스를 모두 선택한 상태에서 생성합니다.
4. 큰 노드 하나를 열고 연결된 하위 노드의 원문 인용으로 이동합니다.
5. 출처 간 연결 한 개와 충돌 한 개를 표시하고 근거 없는 노드는 삭제 또는 확인 필요로 기록합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
등록한 업무 절차·정책·교육자료 소스의 핵심 주제와 하위 개념을 마인드맵으로 만들어 줘. 서로 다른 출처에서 연결되는 노드와 충돌하는 노드를 구분해 줘.
```

### 완료 확인

- [ ] 노드 하나를 선택해 원문 인용과 연결되는지 확인했는가?
- [ ] 완료 결과를 다시 열 수 있음: **핵심·하위·연결·충돌 노드가 있는 마인드맵**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

제공 마인드맵 SVG에서 근거 없는 노드 한 개를 찾습니다.

## 실습 3. 외국어 영상 번역·대본 검수

- 구분: 필수
- 권장 시간: 20분
- 준비 입력: 강사 소유 또는 사용 허가된 외국어 영상과 자막
- 완료 결과: 시간 구간이 있는 번역 대본과 확인 필요 표시

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. 전체 대본·번역 활용이 허가된 강사 소유 영상을 선택하고 자막 언어와 길이를 기록합니다.
4. 30초 단위로 원문과 한국어 번역을 나란히 요청하고 고유명사·숫자·전문용어를 표시합니다.
5. 원본 영상 구간과 세 항목을 대조해 틀린 번역은 직접 수정하고 `[확인 필요]`를 남깁니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
영상 대본을 문단별로 원문｜한국어 번역｜고유명사｜확인 필요 표로 정리해 줘. 말하지 않은 내용을 보충하지 말고 시간 구간을 유지해 줘.
```

### 완료 확인

- [ ] 숫자·이름·전문용어 세 개를 원문 자막과 대조했는가?
- [ ] 완료 결과를 다시 열 수 있음: **시간 구간이 있는 번역 대본과 확인 필요 표시**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

제공된 60초 교육용 대본으로 번역과 검수만 진행합니다.

## 실습 4. 번역 대본을 블로그 초안으로

- 구분: 필수
- 권장 시간: 20분
- 준비 입력: 검수 완료한 허가 대본
- 완료 결과: 출처와 추가 작성이 분리된 블로그 초안

### 천천히 따라 하기

- 완료 결과: 오디오와 원본 불일치·용어 오류 검수 메모
