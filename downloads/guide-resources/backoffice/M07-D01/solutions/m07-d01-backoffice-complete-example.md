# M07-D01 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 교육 신청·업무 요청 자동 보고
- 입력: 요청 유형, 부서 역할, 요청 내용, 우선순위, 상태를 담은 비식별 폼 응답
- 기대 결과: 최소 수집 폼, 응답 Sheet, 업무 보고서 Docs, 업무 결과물 DB
- 주요 위험: 불필요한 개인정보 수집, 열 이름 불일치, 문서 링크·소유자 혼선
- 최종 확인 역할: 폼 소유 역할과 업무 결과물 관리자 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 교육용 가상 폼 응답과 생성 문서 링크
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 업무 요청·교육 신청·만족도 폼 제작
- 결과: Google Form의 교육용 초안
- 검증: 최소 수집
- 과정별 확인 역할: 폼 소유 역할과 업무 결과물 관리자 역할
- 확인한 위험: 불필요한 개인정보 수집, 열 이름 불일치, 문서 링크·소유자 혼선
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
