# [M06-D01] 경영지원 Nano Banana 2·Pro 이미지 선택 실습팩

기준일: 2026-08-08

> 빠른 학습자·도구 비교 확장. 아래 14종 중 2종만 선택합니다. 정규 필수 이미지 세트·스토리보드·Flow 영상을 대체하지 않습니다.

## 이 실습팩의 위치

- 커리큘럼 연결: 필수 커리큘럼은 ChatGPT 이미지 생성·편집과 Google Flow 영상이며 그대로 유지
- 학습 목적: 동일한 이미지 요구를 샷·앵글·비율·텍스트·일관성 기준으로 통제하고 결과를 비교합니다.
- 기능·명칭 보정: 2026-08-08 공식 명칭은 Nano Banana 2(Gemini 3.1 Flash Image)와 Nano Banana Pro(Gemini 3 Pro Image)입니다. 화면에 모델 선택이 없으면 제공 예시로 비교합니다.
- 이 문서는 강사용 상세 절차와 수강생 개인 Notion 정리를 연결하는 로컬 실습자료입니다.

## 시작 전 공통 규칙

1. 교육용 가상 자료 또는 본인이 공개해도 되는 자료만 사용합니다.
2. 기능·앱·모델이 화면에 없으면 현재 상태를 기록하고 대체 실습으로 이동합니다.
3. 생성·등록·공유·취소·삭제 전에는 대상 이름을 다시 읽습니다.
4. AI 응답의 링크·출처·수치·한글·인물·제품 대응을 사람이 확인합니다.
5. 결과 전체를 공용 Notion에 붙이지 않고 개인 Notion에 최소 기록만 남깁니다.

## 실습 1. Nano Banana 2 vs Pro 동일 프롬프트 비교

- 구분: 선택
- 권장 시간: 12분
- 준비 입력: 같은 가상 제품 카드와 같은 프롬프트
- 완료 결과: 두 결과의 한글·세부·일관성·생성 목적 비교표

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. 같은 가상 제품 카드와 같은 프롬프트를 준비하고 현재 화면에 실제 표시된 모델명을 기록합니다.
4. 두 모델을 모두 선택할 수 있을 때만 각각 한 번 생성하고, 없으면 제공 A·B 예시를 사용합니다.
5. 한글·세부 묘사·일관성·목적 적합성을 같은 10점 표로 채점합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.

### 복사해서 쓰는 프롬프트

```text
가상 경영지원 교육용 장면을 16:9로 만들어 줘. 제목은 ‘AI 실습’, 핵심 사물 3개, 읽을 수 있는 한글 라벨 3개를 포함하고 실제 브랜드는 사용하지 마.
```

### 완료 확인

- [ ] 모델 이름을 추측하지 않고 실제 화면 또는 제공 예시의 표시명만 기록했는가?
- [ ] 완료 결과를 다시 열 수 있음: **두 결과의 한글·세부·일관성·생성 목적 비교표**
- [ ] 사람이 수정한 내용과 수정 이유가 한 줄 이상 있음
- [ ] 실제 개인정보·기관 내부자료·고객자료·자격증명이 없음

### 막힐 때

HTML 예시 A·B를 같은 10점 루브릭으로 평가합니다.

## 실습 14. 부모님께 드리는 메시지 카드

- 구분: 선택
- 권장 시간: 12분
- 준비 입력: 본인이 작성한 부모님께 드릴 짧은 감사 문장
- 완료 결과: 원문이 정확한 부모님 감사 카드

### 천천히 따라 하기

1. 준비 입력이 교육용 가상 자료인지 확인하고 실제 개인정보·기관 내부자료가 있으면 즉시 닫습니다.
2. 현재 화면에서 사용할 앱·소스·모델 이름이 실제로 보이는지 확인합니다. 보이지 않으면 추측하지 않습니다.
3. 부모님께 전할 짧은 감사 문장을 본인이 직접 작성하고 맞춤법을 확인합니다.
4. 1:1 카드에 원문을 그대로 넣고 꽃 한 송이·여백만 디자인 요소로 요청합니다.
5. 생성 이미지의 문장을 원문과 한 글자씩 대조하고 가족 사진은 동의가 있을 때만 사용합니다.
6. 결과를 원문·입력과 나란히 놓고 오류 한 개를 수정한 뒤 완료 질문에 답합니다.
7. 개인 Notion에 입력 요약·첫 결과·수정 이유·최종 캡처·원문 링크만 기록합니다.
