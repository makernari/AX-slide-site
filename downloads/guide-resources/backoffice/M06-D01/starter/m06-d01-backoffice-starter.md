# M06-D01 경영지원 시작 파일

> 기준일: 2026-08-08
> 단독 수강: 이 파일과 원자료만으로 시작 가능

## 과제

확정된 교육 정보만으로 포스터를 고치고 의심 메일 발견–신고–완료의 3장면을 설계합니다.

## 사용할 원자료

- m06-d01-backoffice-source-pack.md
- 먼저 원자료 ID와 확정·금지·한계를 표시합니다.

## 네 차시

1. 개선 전 포스터에서 사실·과장·권리 문제를 표시합니다.
2. 대상·메시지·행동 순서로 포스터 전후본을 설계합니다.
3. 고정 요소와 변화 요소를 나눠 3장면을 작성합니다.
4. 시작 프레임·카메라·오류 조건이 있는 Flow 계획을 완성합니다.

## 제출 결과물

- 포스터 전후본
- 3장 이미지 세트
- 업무 영상 스토리보드
- Flow 영상 계획·오류표

## 시작 전 체크

- [ ] 실제 개인정보·내부 화면을 사용하지 않음
- [ ] 원자료 밖 수치·효능·정책을 만들지 않음
- [ ] 자동 생성한 글자·자막·출처를 사람이 확인함
- [ ] 확정 정보·내부 승인·권리 조건를 최종 결과에 기록함
