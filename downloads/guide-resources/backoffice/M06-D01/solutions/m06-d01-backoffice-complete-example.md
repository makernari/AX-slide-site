# M06-D01 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 사내 안전교육 포스터와 안내 영상
- 입력: 교육 대상, 핵심 행동 1개, 교육 일시를 대신하는 가상 일정, 중립적 공간 이미지
- 기대 결과: 가독성이 개선된 포스터, 일관된 3장면, 업무 안내 영상 프롬프트
- 주요 위험: 가상 일정을 실제 공지처럼 보이게 하거나 사람·공간의 연속성이 깨지는 오류
- 최종 확인 역할: 교육 운영 역할과 안전 안내 검토 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 직접 작성한 목적·대상·메시지와 교육용 가상 소재
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 문제가 있는 사내 교육·업무 안내 포스터 분석
- 결과: 포스터 전후본의 교육용 초안
- 검증: 핵심 메시지의 가독성
- 과정별 확인 역할: 교육 운영 역할과 안전 안내 검토 역할
- 확인한 위험: 가상 일정을 실제 공지처럼 보이게 하거나 사람·공간의 연속성이 깨지는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료
