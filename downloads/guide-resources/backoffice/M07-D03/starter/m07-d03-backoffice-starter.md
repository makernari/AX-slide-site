# M07-D03 경영지원 시작 파일

> 기준일: 2026-08-08 · 단독 수강자는 이 파일과 원자료부터 시작

## 과제

12주 가상 업무 요청 데이터를 사람이 먼저 계산한 뒤 ChatGPT 분석과 대조해 사실·해석·가설을 구분합니다.

## 네 차시

1. Sheet 사본·행·열·필터를 확인하고 분석 질문 3개와 검산 셀을 만듭니다.
2. SUM·AVERAGE·필터로 전체·유형별 수치와 이상점·누락값을 확인하고 차트를 만듭니다.
3. CSV 또는 필요한 범위를 ChatGPT에 제공해 사실·변화·가능한 원인·추가 질문을 받습니다.
4. AI 수치를 원본과 대조하고 사실·해석·가설을 구분한 1페이지 보고서를 완성합니다.

## 제출 결과물

- 검산된 Google Sheet
- 핵심 차트 2개
- AI 분석 대조표
- 경영지원 1페이지 보고서

## 완료 기준

- [ ] 원자료의 필수값·허용값·금지·한계를 표시함
- [ ] 실제 개인정보·자격증명·조직 내부자료가 없음
- [ ] 오류 또는 누락 입력을 정상 입력과 분리함
- [ ] 필수값·담당 역할·기한·권한·원본 수치를 원본과 대조함
- [ ] 도구 접근이 없을 때 문서형 대체 결과를 완성함
