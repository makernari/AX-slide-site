# M07-D03 경영지원 완성 예시

> 이 문서는 교육용 가상 사례의 구조 예시입니다. 실제 도구의 고정 출력이나 유일한 정답이 아닙니다.

## 실습 맥락

- 대상: 회의·보고·요청·데이터·자동화 업무를 개선하려는 재직자
- 대표 사례: 가상 교육·업무 요청 처리 데이터 분석
- 입력: 부서·유형·기간별 요청 수, 완료 수, 만족도, 비용
- 기대 결과: 직접 계산한 핵심 수치·차트와 사실–해석–가설이 분리된 1페이지 보고서
- 주요 위험: 완료율·평균을 잘못 계산하거나 부서 차이를 원인으로 단정하는 오류
- 최종 확인 역할: 데이터 소유 역할과 보고서 승인 역할
- 장면: 교육용 가상 조직의 반복 업무
- 근거: 제공된 숫자형 샘플 CSV와 직접 계산한 합계·평균
- 실제 정보 사용: 없음

## 1차시 완성 상태

- 수행: 교육 만족도·업무 요청·예산 중 간단 데이터 확인
- 결과: Google Sheet의 교육용 초안
- 검증: 합계·평균 재계산
- 과정별 확인 역할: 데이터 소유 역할과 보고서 승인 역할
- 확인한 위험: 완료율·평균을 잘못 계산하거나 부서 차이를 원인으로 단정하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 2차시 완성 상태

- 수행: 부서·유형·기간별 주요 수치와 차트 작성
- 결과: 핵심 차트 1~2개의 교육용 초안
- 검증: 차트와 질문의 대응
- 과정별 확인 역할: 데이터 소유 역할과 보고서 승인 역할
- 확인한 위험: 완료율·평균을 잘못 계산하거나 부서 차이를 원인으로 단정하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 3차시 완성 상태

- 수행: 업무 데이터 분석과 개선 의견 생성
- 결과: Google Docs 1페이지 분석 보고서의 교육용 초안
- 검증: 사실·해석·가설 구분
- 과정별 확인 역할: 데이터 소유 역할과 보고서 승인 역할
- 확인한 위험: 완료율·평균을 잘못 계산하거나 부서 차이를 원인으로 단정하는 오류
- 수정: 입력에 없는 표현 한 건을 삭제하고 불명확 항목을 확인 필요로 표시
- 상태: 완료

## 4차시 완성 상태

- 수행: 경영지원 1페이지 분석 보고서 작성
- 결과: Google Docs 1페이지 분석 보고서의 교육용 초안
- 검증: 추가 질문
- 과정별 확인 역할: 데이터 소유 역할과 보고서 승인 역할

## 최종 결과물 묶음

- 핵심 차트 1~2개: 완료 구조와 검증 메모 포함
- Google Docs 1페이지 분석 보고서: 완료 구조와 검증 메모 포함
