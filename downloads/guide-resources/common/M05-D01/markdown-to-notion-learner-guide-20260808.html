BEFORE YOU START

어떤 .md 파일을 직접 작성하나요?

폴더와 파일명으로 읽기 자료와 작성 문서를 먼저 구분합니다.

2
위치·파일역할수강생 행동
README.md파일 목록과 사용 순서먼저 읽기 · 어떤 파일을 쓸지 확인
learner/M05-D01.md일자별 수강생 가이드읽기 중심 · 개인 학습노트로 가져오기는 선택
starter/*-starter.md차시별 내용을 이어 쓰는 시작 문서직접 작성 · 오늘의 기본 작업 파일
templates/*-practice-template.md빈 실습 양식직접 작성 · 시작 파일 대신 또는 함께 사용
templates/*.md체크리스트·설계 카드·기록표필요한 파일만 작성
solutions/*-complete-example.md완성 구조 비교 자료참고만 하기 · 내 답으로 덮어쓰지 않기
starter/*-source-pack.md교육용 가상 원자료입력 자료로 읽기 · 원문을 임의 수정하지 않기
오늘의 기본 선택
starter/*-starter.md 한 개를 먼저 가져오고, 강사가 안내한 templates/*.md만 추가합니다. 모든 파일을 한꺼번에 가져올 필요는 없습니다.

작성본

내 판단·프롬프트·오류·결과·다음 행동을 기록합니다. 실제 개인정보나 기관 내부자료는 넣지 않습니다.

비교본

완성 예시는 정답 복사본이 아닙니다. 구성과 사람 검수 항목만 비교합니다.

수업자료/
├─ README.md ← 파일 설명
├─ starter/
│ └─ m05-d01-[과정]-starter.md ← 기본 작성 파일
├─ templates/
│ └─ m05-d01-[과정]-practice-template.md ← 빈 양식
└─ solutions/
└─ m05-d01-[과정]-complete-example.md ← 비교 자료

링크를 눌렀더니 글자만 보일 때

  1. 브라우저의 저장 기능을 사용합니다.
  2. 파일명을 확인하고 끝을 .md로 둡니다.
  3. .txt가 붙었다면 파일 탐색기에서 확장자를 .md로 수정합니다.

ZIP을 받았을 때

  1. 압축 파일 안에서 바로 열지 않습니다.
  2. 먼저 새 폴더에 압축을 풉니다.
  3. 현재 일자의 starter와 templates만 찾습니다.
원본 보관
내려받은 원본은 과정 폴더에 그대로 둡니다. Notion에서 작성한 내용은 원본 .md 파일에 자동으로 되돌아가지 않습니다.

ONE FILE OR ZIP

한 개씩 가져올까요, ZIP으로 가져올까요?

첫 시간에는 필요한 파일만 가져오는 경로가 가장 안전합니다.

6
첫 시간 권장

현재 일자 파일만 선택

  1. starter/*-starter.md 선택
  2. 강사가 지정한 templates/*.md 추가
  3. Text & Markdown으로 가져오기
  4. 과정 홈 아래로 이동

장점: 중복과 혼선을 줄이고 현재 차시 결과에 집중할 수 있습니다.

강사 안내 시

폴더 구조를 ZIP으로 가져오기

  1. 폴더 전체가 들어 있는 ZIP 확인
  2. 설정 → 가져오기에서 ZIP 변환 선택
  3. 생성된 페이지와 폴더 구조 확인
  4. 현재 일자 페이지만 수업 노트로 이동

주의: PDF는 ZIP 변환 대상과 다를 수 있으며, 불필요한 답안 파일까지 한꺼번에 가져오지 않습니다.

중복 방지
같은 파일을 다시 가져오면 기존 페이지를 업데이트하는 것이 아니라 새 페이지가 추가될 수 있습니다. 다시 가져오기 전에 사이드바에서 같은 제목이 있는지 확인합니다.

1~2개 파일

개별 가져오기
가장 빠르고 오류 확인이 쉽습니다.

여러 Markdown

다중 선택
같은 가져오기에서 여러 .md를 선택할 수 있습니다.

전체 작업 페이지는 비공개
상세 프롬프트·오류·원자료가 있는 작성본은 게시하지 않습니다. 첫날 만드는 별도의 공개 학습 대시보드에는 비식별 자기소개와 공개 가능한 학습 요약만 둡니다.

문제확인·복구
파일이 .txt로 저장됨파일 확장자 표시를 켜고 끝을 .md로 바꾼 뒤 다시 가져옵니다.
Notion에서 편집할 수 없음연결 프로그램으로 열기를 사용했는지 확인합니다. 읽기 전용 미리보기라면 설정 → 가져오기 → Text & Markdown으로 다시 가져옵니다.
가져오기 메뉴가 보이지 않음모바일이 아닌 데스크톱 앱·웹인지, 개인 워크스페이스에 페이지 생성 권한이 있는지 확인합니다.
표·링크·체크박스 모양이 달라짐표준 Markdown 내용이 빠졌는지 먼저 확인하고, 복잡한 서식은 Notion에서 간단히 다시 정리합니다.
같은 페이지가 두 개 생김가져오기는 기존 페이지 갱신이 아닙니다. 작성량과 수정 시각을 비교한 뒤 강사 확인 후 불필요한 복사본을 정리합니다.
실제 업무자료를 넣어도 되는지 모름넣지 않습니다. 가상·비식별 자료로 바꾸고 사람의 확인 항목만 기록합니다.
